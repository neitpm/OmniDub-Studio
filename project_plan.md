# Project Plan – Chinese → Vietnamese Dubbing App (Monolith MVP)

## 1️⃣ Goal
Create a single‑process Python application that takes a short Chinese video (1‑3 min) and produces a dubbed Vietnamese version while preserving timestamps.

## 2️⃣ High‑level Pipeline
```
Video → extract audio (FFmpeg) → STT (faster‑whisper medium, int8_float16) → batch translate (Helsinki‑NLP/opus‑mt‑zh‑vi) → TTS (MMS Vietnamese via 🤗 Transformers VitsModel) → align timestamps → merge audio → output video
```

## 3️⃣ Folder Layout (all under the workspace root `d:\translate`)
| Folder | Purpose |
|--------|---------|
| `data/` | JSON transcripts, translations, generated .srt files |
| `audio/` | Original audio `source.wav` |
| `segments/` | Per‑segment WAV files generated by TTS |
| `output/` | Final video `dubbed_video.mp4` |

## 4️⃣ Data structures
```json
{
  "segments": [
    {
      "id": "0001",
      "start": 10.2,
      "end": 13.8,
      "source": "你到底是谁？",
      "translation": "Rốt cuộc ngươi là ai?",
      "audio": "segments/0001.wav"
    }
    // …
  ],
  "metadata": {
    "video_file": "input.mp4",
    "audio_file": "audio/source.wav",
    "stt_model": "medium",
    "tts_model": "mms‑tts‑vie",
    "translation_model": "opus‑mt‑zh‑vi",
    "pipeline_version": "MVP1"
  }
}
```

## 6️⃣ Timeline (estimated effort)
| Milestone | Tasks | ETA |
|-----------|-------|-----|
| **MVP 1** (STT → SRT) | - Extract audio<br>- Run faster‑whisper (medium, int8_float16) with fallback to small<br>- Export `subtitle_zh.srt` and `transcript.json` | 2 days |

## 7️⃣ Important Implementation Details
- **GPU safety**: wrap model loading in `try/except`; fall back to a smaller model if VRAM is insufficient.
- **Batch translation**: collect `source` strings into a list, call `translator(texts, ...)` once, then map results back to segment order.
- **Timestamp alignment**: after TTS we compute `audio_duration = wav_len / sr`. If it differs from `segment.end‑segment.start` by > 0.1 s we apply a mild `atempo` filter (max ±10 %).
- **Intermediate files**: always write to the folders defined above; this allows re‑running later steps without re‑doing earlier ones.
- **Future scaling**: once the monolith is stable we can extract the three stages (STT, Translation, TTS) into separate micro‑services.
